# Source Code

This directory contains the core source code for the Prediction Market Fund project.

## Project Structure

- `agent/`: Contains the core logic for the trading agent.
- `core/`: Defines the core data structures and types used throughout the application.
- `dashboard/`: Components for the real-time dashboard.
- `data/`: Data sources and fetching logic.
- `engine/`: The main simulation and trading engine.
- `portfolio/`: Portfolio and risk management components.
- `reporting/`: Generation of investment memos and other reports.
- `tests/`: Unit and integration tests.
