# Prediction Market Fund

## Vision

**Mission:** Maximize risk-adjusted returns by autonomously trading on Polymarket prediction markets in a simulated 'Paper Trading' environment.

**Vision:** A fully autonomous, self-improving hedge fund that demonstrates superior decision-making through transparent reasoning and rigorous benchmarking.

## Constitution

This project is governed by the following core principles:

1.  **Probabilistic Thinking:** All trading decisions must be based on positive Expected Value (EV) calculations derived from probabilistic models, not binary predictions.
2.  **Capital Preservation:** Survival is the primary objective. Risk management protocols must prevent catastrophic loss, even in a simulated environment.
3.  **Radical Transparency:** No black boxes. Every trade must be accompanied by a human-readable 'Investment Memo' explaining the thesis, sources, and logic.
4.  **Continuous Learning:** The system must learn from every outcome. Automated post-mortems are required to close the feedback loop between prediction and reality.
