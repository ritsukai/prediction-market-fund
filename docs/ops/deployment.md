# Deployment

This document outlines the process for deploying the Prediction Market Fund application.

## Prerequisites

- Python 3.11+
- Poetry for dependency management

## Steps

1.  **Install Dependencies:**
    ```bash
    poetry install
    ```

2.  **Run the Simulation:**
    ```bash
    poetry run python main.py
    ```
